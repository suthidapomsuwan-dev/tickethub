# TicketHub – Online Concert Ticket Booking System

## 1. รายละเอียดโครงการ

TicketHub เป็นเว็บแอปพลิเคชันสำหรับจองบัตรคอนเสิร์ตออนไลน์ พัฒนาด้วย React และเชื่อมต่อ Firebase Realtime Database เพื่อจัดเก็บและจัดการข้อมูลของระบบ

ผู้ใช้งานสามารถดูรายการคอนเสิร์ต ค้นหาคอนเสิร์ต ดูรายละเอียด เลือกรอบการแสดงและที่นั่ง จองบัตร และตรวจสอบประวัติการจองได้ตามฟังก์ชันที่ระบบรองรับ

ระบบผู้ดูแลสามารถจัดการข้อมูลคอนเสิร์ตและตรวจสอบข้อมูลการจองได้ตามสิทธิ์ที่กำหนด

## 2. วัตถุประสงค์

1. เพื่อพัฒนาเว็บแอปพลิเคชันสำหรับจองบัตรคอนเสิร์ตออนไลน์
2. เพื่อฝึกการพัฒนาเว็บไซต์ด้วย React และ JavaScript
3. เพื่อเชื่อมต่อและจัดการข้อมูลผ่าน Firebase Realtime Database
4. เพื่อพัฒนาระบบนำทางและส่วนติดต่อผู้ใช้ให้ใช้งานได้สะดวก
5. เพื่อทดสอบและเผยแพร่เว็บแอปพลิเคชันที่สามารถใช้งานผ่านเว็บเบราว์เซอร์ได้

## 3. เทคโนโลยีที่ใช้

- React – พัฒนาส่วนติดต่อผู้ใช้
- Vite – จัดการโครงการและรัน Development Server
- JavaScript – พัฒนาฟังก์ชันของระบบ
- Firebase Realtime Database – จัดเก็บและอ่านข้อมูล
- React Router – จัดการเส้นทางระหว่างหน้าเว็บ
- CSS – ตกแต่งและจัดรูปแบบหน้าจอ
- Node.js และ npm – ใช้ติดตั้ง Dependencies และรันคำสั่งของโครงการ
- Git และ GitHub – ใช้ควบคุมเวอร์ชันและจัดเก็บ Source Code

## 4. ความต้องการของระบบ

ก่อนติดตั้งโครงการ ควรมีโปรแกรมดังต่อไปนี้

- Node.js เวอร์ชันที่รองรับ Dependencies ของโครงการ
- npm ซึ่งติดตั้งมาพร้อมกับ Node.js
- Visual Studio Code หรือโปรแกรมแก้ไขโค้ดอื่น
- เว็บเบราว์เซอร์ เช่น Google Chrome
- การเชื่อมต่ออินเทอร์เน็ตสำหรับใช้งาน Firebase

ตรวจสอบการติดตั้ง Node.js และ npm ด้วยคำสั่ง


หากคำสั่งแสดงหมายเลขเวอร์ชัน แสดงว่าสามารถเรียกใช้งานโปรแกรมผ่าน Terminal ได้

## 6. วิธีติดตั้งโครงการ

### 6.1 ดาวน์โหลด Source Code

1. เปิด GitHub Repository ของ TicketHub
2. เลือกเมนู Code
3. เลือก Download ZIP
4. แตกไฟล์ ZIP ไปยังโฟลเดอร์ที่ต้องการ

หากใช้ Git สามารถ Clone Repository ได้ด้วยคำสั่ง

```bash
git clone <GITHUB_REPOSITORY_URL>
cd <PROJECT_FOLDER>
```

เปลี่ยน `<GITHUB_REPOSITORY_URL>` เป็น URL ของ Repository จริง และ `<PROJECT_FOLDER>` เป็นชื่อโฟลเดอร์ที่ได้จากการ Clone

### 6.2 เปิดโครงการ

เปิดโฟลเดอร์โครงการด้วย Visual Studio Code จากนั้นเปิด Terminal โดยเลือกเมนู Terminal → New Terminal

ตรวจสอบว่า Terminal อยู่ในโฟลเดอร์เดียวกับไฟล์ `package.json`

### 6.3 ติดตั้ง Dependencies

รันคำสั่งต่อไปนี้

```bash
npm install
```

คำสั่งนี้ใช้ติดตั้งไลบรารีที่ระบุไว้ใน `package.json` หากเกิดข้อผิดพลาด ให้ตรวจสอบเวอร์ชัน Node.js การเชื่อมต่ออินเทอร์เน็ต และข้อความแจ้งเตือนใน Terminal

## 7. การตั้งค่า Firebase

TicketHub ใช้ Firebase Realtime Database สำหรับจัดเก็บและเรียกใช้ข้อมูลของระบบ

ก่อนใช้งาน ให้ตรวจสอบว่าโครงการ Firebase ได้รับการตั้งค่าแล้ว และไฟล์เชื่อมต่อ Firebase ภายใน Source Code ใช้ค่าของ Firebase Project ที่ถูกต้อง

ขั้นตอนตรวจสอบมีดังนี้

1. เปิด Firebase Console
2. เลือก Firebase Project ของ TicketHub
3. เปิด Realtime Database
4. ตรวจสอบว่ามีข้อมูลตามโครงสร้างที่ระบบใช้งาน
5. ตรวจสอบค่า Database URL และการตั้งค่า Firebase ใน Source Code
6. ตรวจสอบ Database Rules ให้เหมาะสมกับสิทธิ์ของผู้ใช้และผู้ดูแลระบบ
7. เปิดเว็บไซต์และทดสอบการอ่านข้อมูลจากฐานข้อมูล

ไฟล์ `firebase-data.json` เป็นไฟล์ข้อมูลสำหรับนำเข้า Realtime Database หากมีการจัดเตรียมไฟล์ดังกล่าวไว้ในโครงการ ให้ตรวจสอบว่าโครงสร้าง JSON สอดคล้องกับ Path ที่ Source Code เรียกใช้งาน

ข้อควรระวัง: ไม่ควรเปิดสิทธิ์อ่านและเขียนฐานข้อมูลทั้งหมดโดยไม่มีการจำกัดสิทธิ์ และไม่ควรเผยแพร่รหัสผ่าน Service Account หรือข้อมูลรับรองส่วนตัวลงใน Repository

## 8. วิธีเปิดใช้งานเว็บไซต์ในเครื่อง

หลังจากติดตั้ง Dependencies และตั้งค่า Firebase แล้ว ให้รันคำสั่ง

```bash
npm run dev
```

เมื่อ Development Server เริ่มทำงาน Vite จะแสดง URL ใน Terminal โดยทั่วไปจะเป็น

```text
http://localhost:5173
```

เปิด URL ที่แสดงใน Terminal ผ่านเว็บเบราว์เซอร์เพื่อใช้งานเว็บไซต์

หาก Port 5173 ถูกใช้งานอยู่ Vite อาจเลือก Port อื่นโดยอัตโนมัติ ให้ใช้ URL ที่แสดงจริงใน Terminal

หากต้องการหยุด Development Server ให้กลับไปที่ Terminal แล้วกด `Ctrl + C`

## 9. ฟังก์ชันของระบบ

### 9.1 ผู้ใช้งาน

- ดูรายการคอนเสิร์ต
- ค้นหาและเลือกดูคอนเสิร์ตที่สนใจ
- ดูรายละเอียดคอนเสิร์ต
- เลือกรอบการแสดงและที่นั่งตามที่ระบบรองรับ
- ดำเนินการจองบัตรคอนเสิร์ต
- ตรวจสอบประวัติการจอง
- ดูข้อมูลบัตรอิเล็กทรอนิกส์ หากมีการพัฒนาฟังก์ชันดังกล่าว

### 9.2 ผู้ดูแลระบบ

- เข้าสู่ระบบผู้ดูแลตามวิธีการยืนยันตัวตนที่โครงการกำหนด
- ดูข้อมูลคอนเสิร์ต
- เพิ่มข้อมูลคอนเสิร์ต
- แก้ไขข้อมูลคอนเสิร์ต
- ลบข้อมูลคอนเสิร์ต
- ตรวจสอบข้อมูลการจองตามสิทธิ์ที่ได้รับ

หมายเหตุ: รายการฟังก์ชันข้างต้นเป็นขอบเขตที่ต้องตรวจสอบกับระบบจริงก่อนส่งงาน ควรระบุว่าฟังก์ชันใดพัฒนาเสร็จแล้ว และไม่ควรระบุว่ารองรับฟังก์ชันที่ยังไม่ได้ทำงานจริง

## 10. วิธีตรวจสอบและทดสอบระบบเบื้องต้น

หลังเปิดเว็บไซต์แล้ว ให้ตรวจสอบการทำงานดังนี้

1. เปิดหน้าหลักและตรวจสอบว่าเว็บไซต์แสดงผลได้
2. ตรวจสอบว่ารายการคอนเสิร์ตแสดงข้อมูลจาก Firebase
3. ทดลองค้นหาและเปิดดูรายละเอียดคอนเสิร์ต
4. ทดลองเลือกรอบการแสดงและที่นั่ง หากมีฟังก์ชันดังกล่าว
5. ทดลองจองบัตรและตรวจสอบผลลัพธ์ในระบบ
6. ทดลองเปิดประวัติการจอง
7. ทดลองเข้าสู่ระบบผู้ดูแลและจัดการข้อมูลตามสิทธิ์
8. ทดสอบการแสดงผลบนหน้าจอขนาดต่าง ๆ
9. ตรวจสอบกรณีไม่มีข้อมูลหรือเกิดข้อผิดพลาดในการเชื่อมต่อ
10. ตรวจสอบว่าไม่มีข้อผิดพลาดที่ทำให้ฟังก์ชันหลักใช้งานไม่ได้

ควรบันทึกผลการทดสอบแต่ละกรณี พร้อมระบุผลที่คาดหวัง ผลที่เกิดขึ้นจริง และสถานะผ่านหรือไม่ผ่าน

## 11. การสร้าง Production Build

ก่อนนำเว็บไซต์ไปเผยแพร่ ให้ตรวจสอบว่าโครงการสามารถสร้าง Production Build ได้ด้วยคำสั่ง

```bash
npm run build
```

หากคำสั่งทำงานสำเร็จ Vite จะสร้างไฟล์สำหรับเผยแพร่ไว้ในโฟลเดอร์ `dist/` ตามการตั้งค่าของโครงการ

หากต้องการตรวจสอบ Production Build ในเครื่อง สามารถใช้คำสั่ง

```bash
npm run preview
```

จากนั้นเปิด URL ที่แสดงใน Terminal เพื่อทดสอบไฟล์ Build ก่อน Deploy

หมายเหตุ: คำสั่งดังกล่าวต้องมี Scripts ที่เกี่ยวข้องกำหนดไว้ใน `package.json`
